Produit A

Étude de Marché type — Exemple Pizzeria

1. Résumé exécutif

Marché local ~8-12 M€ (pizzeria Montpellier agglo). 45 concurrents directs. Panier moyen 18-22€. CA prévisionnel An 1 : 220 k€. Marge brute 65%.

2. Analyse PESTEL

  • Politique : plan Cœur de Métropole, zones piétonnes favorables
  • Économique : pouvoir d'achat moyen, tourisme 3,5M visiteurs/an
  • Socioculturel : tendance street-food premium, végétarien +22%
  • Technologique : click & collect, Uber Eats, Instagram food
  • Environnemental : emballages compostables, local sourcing
  • Légal : normes HACCP, ERP cat. 5

3. 5 forces de Porter

Concurrence intra-sectorielle : élevée · Nouveaux entrants : forte · Fournisseurs : moyenne · Clients : élevée · Substituts : élevée (burgers, tacos).

4. Chiffres clés (INSEE / Banque de France)

  • CA médian secteur NAF 5610C : 240 k€
  • Marge brute : 62-68%
  • Marge nette : 3-7%
  • BFR : 15-25 jours de CA

5. Clients & concurrence

Cible : 18-45 ans, CSP+, centre-ville + touristes. Concurrents : 3 chains (Domino's, Pizza Paï, Del Arte) + 42 indépendants. Zone blanche : pizza napolitaine premium à emporter.

6. SWOT

Forces : concept clair, emplacement. Faiblesses : notoriété initiale. Opportunités : tourisme, livraison. Menaces : chains, pouvoir d'achat.

Sources : INSEE, Banque de France (NAF 5610C), CCI Hérault, Statista, Xerfi.
